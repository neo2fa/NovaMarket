🛡️ NovaMarket: Private AI-Driven Commerce
NovaMarket is a decentralized marketplace for Digital
assets, powered by NOVA for encryption and NEAR for payments.

🌟 How it works:
Encryption: Sellers upload files which are encrypted via 
NOVA SDK before reaching any server.
AI Agent: An automated agent monitors the NEAR blockchainfor payments.
Delivery: Once payment is confirmed, the AI agent securely 
releases the decryption keys to the buyer.
🛠️ NOVA Integration:
We use NOVA's Private Vaults to ensure that digital goods (e-books, code) 
remain private until the moment of purchase.

🚀 Track: Agentic E-commerce
This project fulfills the "Agentic E-commerce" challenge by automating the 
personalized sale and automated delivery of digital goods.
